# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Изменения, которых ещё нет в релизе, пишем в раздел «Unreleased»; скрипт `npm run release` переносит их под номер версии.

## [Unreleased]
### Добавлено
- Жест горизонтального свайпа и плавный слайд-переход между вкладками папок чатов («Все», «Личные», «Новые» и пользовательские папки).
- Плавные анимации переходов между вкладками и экранами (слайд экранов, профиля и диалога пересылки).

### Изменено
- Установлен оригинальный значок архива чатов Telegram для Android (`chats_archive.webp`).

## [1.1.0] - 2026-10-05### Добавлено
- Мгновенный запуск: все файлы приложения кэшируются Service Worker заранее и отдаются из кэша; шрифт Roboto лежит внутри; список чатов и последние переписки показываются сразу из локального кэша.
- Уведомления: браузер, Windows (значок в трее, окно скрывается при закрытии) и Android (нативные уведомления, тап открывает чат, служба «Работа в фоне»). Страница «Уведомления и звуки» в настройках; чаты без звука не уведомляют; счётчик на значке.
- Единый стек «Назад»: жест Android, кнопка браузера и Esc закрывают верхний слой (меню, диалог, просмотр, эмодзи, выбор, поиск, профиль, чат, подстраница настроек, вкладка).
- Список чатов: ряд историй слева от заголовка, черновики, маленькая кнопка камеры, размеры по замерам Telegram для Android.
- Релизы по git-тегам, `CHANGELOG.md`, скрипт `npm run release`, инструкция `docs/RELEASING.md`.

### Исправлено
- В приложениях Android/Windows не загружались иконки и часть ресурсов (запросы мимо Service Worker не доходили до файлов внутри приложения; относительный `url()` внутри `var()` указывал не туда).

## [1.0.0] - 2026-10-05
### Добавлено
- Первая версия: список чатов, переписка, профиль, настройки, обои и темы чатов, моды, 5 языков; приложения для Android и Windows.
